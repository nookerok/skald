# SKALD — Правила онтологии мира
## Версия 1.0 | Derived from: World Bible + Kernel Algorithm v1.0

---

## A1. Состав реальности

**Правило:** Реальность состоит из трёх неразделимых аспектов:
- **Structure** → Rules (что может существовать)
- **State** → World State (что существует сейчас)
- **Process** → Events (как состояния изменяются)

**Применение:** Любой игровой объект должен быть определён через все три аспекта. Нельзя создать объект без Rules (как он может существовать?), без State (где он сейчас?) и без Process (как он изменяется?).

---

## A2. Первичность отношений

**Правило:** Первичны отношения (Relations), не объекты. Объекты существуют только в системе отношений.

**MUST:**
- Ни один игровой объект не существует без набора Relations, которые его порождают.
- Создавая NPC, не начинай с «уровень 5, сила 12». Начни с Relations: `NPC --работает в--> Кузница`, `NPC --обучен--> Мастер`, `NPC --поставляет--> Деревня`.
- В БД каждый Entity хранит только `id` и `state` (persistence, integrity, resources, location). Всё остальное — Relations в графе.
- Нет таблицы `npc_stats`.

**ANTI-PATTERN:** «У этого меча урон 15». Допустимо: «Меч --связан с--> Кузнец --имеет репутацию--> Высокая → качество ковки высокое → урон производно от Relations».

---

## A3. Пространство как следствие отношений

**Правило:** Пространство — следствие отношений, не контейнер. Два места могут быть далеко геометрически, но близко структурно.

**MUST:**
- Каждая локация должна иметь причину существования в графе отношений.
- «Пустое» пространство между точками интереса не существует как объект.
- Дорога между локациями существует не потому что «нужен путь», а потому что 200+ Events типа `move` создали стабильный Pattern Relations.
- Дорога может исчезнуть, если Relations прервутся.

**Нелокальность:** «Складки» пространства — не fast-travel, а устойчивые topological shortcuts в графе Relations. Игрок открывает их через понимание, не через пункт меню.

---

## A4. Время как частичный порядок

**Правило:** Время — частичный порядок изменений, не течение и не субстанция. Причинность линейна, время — нет.

**MUST:**
- События в разных регионах могут быть причинно несравнимы.
- Не используй глобальный таймер для синхронизации мирового состояния.
- Нет «квест активен с 12:00 до 18:00». Есть: «После Event E_2847 → Pattern становится dirty → через Causal Horizon Secondary NPC получают Intent».

**ANTI-PATTERN:** «Через 3 игровых дня произойдёт нападение» — допустимо только если нападение вызвано накоплением конкретных Events.

---

## A5. Частичная познаваемость

**Правило:** Любое явление объяснимо, но полная картина недостижима, потому что наблюдатель — часть системы.

**SHOULD:**
- Интерфейс игрока показывает Observation, не Truth.
- NPC и игрок могут иметь несовместимые, но локально корректные модели одного Pattern.
- Игрок видит: «Устойчивый Pattern с обратной связью (Stability 0.87)». NPC видит: «Гнев духа реки». Оба Observation валидны.
- UI не должен содержать метку «ИСТИНА» — только «Ты видишь...».

---

## H1. История необратима

**Правило:** Руины нельзя «починить». Разрушенный Pattern не восстанавливается в исходную форму.

**MUST:**
- Распавшийся Pattern либо распадается в ambient Relations, либо эмерджирует как новый Pattern.
- Город погиб → через время на его месте может эмерджировать Settlement, но это новый Pattern с другой Identity.
- Старые Relations не наследуются автоматически — только через Myth Pattern (искажённая память).

---

## H2. История накапливается

**Правило:** Ни один цикл не начинается с нуля. Event Log хранит ВСЕ события: успешные, отклонённые, прерванные.

**MUST:**
- Каждый FAILED Event записывается и может порождать последствия (обучение, табу, адаптация).
- Миф = Lossy Compression Event History + Semantic Drift. Может быть фактически неверен, но системно правильным.

---

## H4. Катастрофы преобразуют, а не стирают

**Правило:** Империи становятся горами, дороги — реками. География сама является археологией.

**MUST:**
- Каждая гора, река и разлом — следствие древних процессов.
- Ландшафт — единственный сохранившийся исторический документ.
- История записана в ландшафте, не в книгах.

---

## Замкнутость мира

**Правило:** Мир причинно-следственно замкнут. Нет параллельных вселенных, внешних авторов, произвольных измерений.

**MUST:**
- Ничто не появляется извне без причины, существующей внутри модели мира.
- Нет лора «потому что красиво». Каждый факт мира следует из аксиом или исторических событий.

---

## Универсальный закон масштаба

**Правило:** Любой устойчивый паттерн имеет естественный масштаб существования. При превышении предела паттерн теряет устойчивость и распадается или трансформируется.

**MUST:**
- Город не может бесконечно расти — scale_penalty превышает cohesion при scale > σ₀.
- Игрок не может бесконечно расширять влияние. Попытка создать слишком большой паттерн (империя, культ) приводит к деградации или катастрофе.
- Нет централизованных империй (ограничено законом масштаба).

---

## Жизнь и разум

**Правило:** Живым является не объект, а паттерн, способный одновременно: поддерживать структуру, изменять себя, изменять окружающие отношения, сохранять непрерывность, порождать новые паттерны.

**Разум** — способность строить модели отношений и сознательно изменять их.

**Дух** — устойчивый самоорганизующийся паттерн отношений. Не отдельная личность. Спектр: камень → дерево → лес → долина → город → цивилизация.

**Смерть** — распад паттерна с распределением отношений. Личность исчезает безвозвратно.
