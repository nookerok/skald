# SKALD — Правила миростроительства
## Версия 1.0 | Derived from: World Bible — Главы 4-7

---

## Глава 4. Мир и география

### Масштаб
- Один континент (размером с Европу).
- Океан — загадка, другие континенты существуют, но долго недостижимы.

### Скрытая вертикаль
- Древние подземные структуры, рукотворные недра.
- Области по масштабу сопоставимы с поверхностью.

### География как археология
- Единый континент с естественными барьерами.
- Рельеф — следствие древних процессов: гигантские разломы, окаменевшие сооружения, моря после катастроф, леса на останках структур.
- Каждая гора, река и разлом — следствие древних процессов.
- Ландшафт — единственный сохранившийся исторический документ.

**MUST:**
- Нет биомов без причины.
- Каждая локация имеет ≥1 причину существования в графе Relations.
- География объяснена древними процессами (циклы, катастрофы).

### Исследованность
- Забытый мир. Не terra incognita — люди думают, что знают историю, но почти всё неверно.
- Игрок открывает не новые земли, а настоящую историю.

### Нелокальность
- Пространство может быть нелокальным: глубокие области соприкасаются с далёкими.
- Связь через законы мира, а не расстояние.
- Древние дороги, скрытые проходы, топологические «складки» — естественные следствия аксиомы А3.

**MUST:**
- «Складки» обоснованы древними структурами, не магией «потому что».
- Нелокальная навигация: игрок может найти «складки», но только если понимает Relations региона.
- Карта — не евклидова.

## Глава 5. История

### Исторические инварианты

| Инвариант | Смысл |
|-----------|-------|
| H1. История необратима | Руины нельзя «починить». Разрушенный Pattern не восстанавливается в исходную форму. |
| H2. История накапливается | Ни один цикл не начинается с нуля. Event Log хранит всё. |
| H3. История распределена | Нет единственного носителя истины. |
| H4. Катастрофы преобразуют, а не стирают | Империи становятся горами, дороги — реками. |
| H5. Любое знание изменяет носителя | Познаваемость частична, наблюдатель — часть системы. |

### Циклы
- Фрактальная эволюция: повторяющийся структурный паттерн на разных масштабах, но никогда не повторяется буквально.

### Последняя катастрофа
- Не событие, а процесс: рост сложности → превышение устойчивости → каскадные перестройки → потеря способности поддерживать собственную структуру.

### Происхождение современных народов
- Биологические потомки выживших.
- Культурно и философски — совершенно другие.

### Почему исчезли древние
- Фундаментальное ограничение познаваемости (Аксиома 5).
- Они понимали больше всех, но столкнулись с последствиями, невозможными вычислить полностью.

### Забвение
- Древние почти не пользовались книгами.
- Знания «записаны» в архитектуре, дорогах, ландшафте, культах, ремёслах, устойчивых отношениях.
- Археология в SKALD = восстановление структуры отношений, а не поиск текста.

**MUST:**
- История записана в ландшафте, не в книгах.
- Руины нельзя «прочитать» — их нужно понять как Pattern Relations.
- Нет единого «источника знаний». Информация разбросана между ландшафтом, языками, ремёслами, мифами, духами.

## Глава 6. Общество и культура

### Социологические инварианты

| Инвариант | Смысл |
|-----------|-------|
| И1. Общество — живой паттерн | Нельзя уничтожить, убив правителя. |
| И2. Власть = способность изменять отношения | Нет титулов без Relations. |
| И3. Экономика = обмен устойчивостью | Доверие, обязательства, знания, плодородные отношения с землёй. |
| И4. Религия = технология существования | Не объяснение происхождения. |
| И5. Конфликты = несовместимые модели устойчивости | Не добро vs зло. |

### Культурные инварианты

| Инвариант | Смысл |
|-----------|-------|
| К1. Мир не требует правильной интерпретации | Практика эффективна без понимания причины. |
| К2. Традиция сохраняет больше истины, чем теория | |
| К3. Культура = локальная оптимизация | Нет универсально правильной культуры. |
| К4. Большинство людей никогда не увидит «истинный» мир | |
| К5. Повседневность выглядит обычной | |

### Политика
- Города-государства, местные союзы.
- Власть через устойчивые сети отношений.
- Нет централизованных империй (ограничено законом масштаба).

### Экономика
- Ремесло, знания, обязательства, память важнее накопления богатства.
- Формально — обмен товарами. По сути — сеть обязательств, доверия, репутации и знаний.
- Деньги могут существовать, но вторичны.

### Религия
- Практический анимизм без всемогущих богов.
- Разные культы могут быть частично правы одновременно.
- Культ формируется дольше торгового союза.

### Культурное разнообразие
- Разные регионы несут следы разных древних центров, усиленные географической изоляцией.

### Конфликты
- Споры об истории, страх глубокой магии, разные отношения с духами-места.
- ~20% регионов в конфликте, не 100%.

### Языки
- Несколько самостоятельных языков.
- Письменность древних — редкое и опасное знание.

### Фрагментация (иерархия причин)

| Уровень | Причина |
|---------|---------|
| D | Когнитивный предел сети отношений (фундаментальный закон) |
| C | Духи мест (системное сопротивление разрушению локальных паттернов) |
| A | География (барьеры и стоимость коммуникации) |
| E | Историческая память (коллективные мифы о едином мире, который «плохо закончился») |

**MUST:**
- Нет «злой империи» как причины фрагментации.
- Фрагментация следует из фундаментальных законов.

## Глава 7. Повседневная жизнь

### Питание
- Земледелие как отношения с землёй + ремесленное производство.
- Люди называют это просто земледелием и кухней.
- Эффективность без понимания причины (К1).

### Путешествия
- Большинство пользуется обычными дорогами, лодками, тропами.
- «Живые пути» и нелокальные связи известны лишь опытным проводникам и странникам.

### Лечение
- Сначала травы, ремесло, традиционные методы.
- Глубокое понимание отношений тела — редкое искусство, не поведневная медицина.

### Жилище
- Люди строят «как принято», «где дух позволяет», часто на останках древних.
- Не осознают, что интуитивный выбор места — следование фундаментальным отношениям.

### Торговля
- Формально — обмен товарами.
- По сути — сеть обязательств, доверия, репутации и знаний.
- Деньги вторичны.

## Глава 8. Разумные существа

### Природа
- Один биологический вид (люди), множество культур.
- Другие формы разума появятся только если естественно следуют из аксиом.

### Континуум разума
- Несколько осей: скорость мышления, масштаб, глубина памяти, способность к моделированию, способность менять отношения.
- Человек занимает одну область.

### Наследие древних
- Ничего не осталось в плане разумных существ.
- Древние изменили сам мир, а не населили его бессмертными слугами.

### Игрок
- Часть мира, подчиняется фундаментальным законам.
- Обладает редким свойством, позволяющим взаимодействовать с законами иначе.
- Свойство не даёт превосходства и само требует исследования.
- Мир не знает об игроке заранее; игрок становится заметен только через действия.

## Анти-референсы (архитектурные запреты)

- Нет избранного героя
- Нет бинарной морали
- Нет магии только как оружия
- Нет пустого открытого мира
- Нет квестового автомата
- Нет уровней как меры силы
- Нет магических школ с каталогом заклинаний
- Нет бессмертных NPC-квестгиверов
- Нет биомов без причины
- Нет всеведущих богов
- Нет лора невыводимого из законов мира
