# SKALD — Правила магии
## Версия 1.0 | Derived from: World Bible — Глава 3

---

## Определение

**Правило:** Магия — искусство переписывания отношений через участие, а не через контроль.

**MUST:**
- Маг становится частью процесса, который хочет изменить.
- Магия — свойство действия, не человека.
- Нет «магов по рождению».
- Нет школ магии, каталогов заклинаний, маны.

---

## Форма магии

**Правило:** Любое действие, изменяющее сеть отношений:
- Путешествие
- Строительство
- Песня
- Ритуал
- Ковка
- Выращивание
- Переговоры
- Жертва
- Изменение тела

**MUST:**
- Это не школы магии — это разные способы одного фундаментального действия.
- «Слабая магия» повседневности: кузнец, понимающий металл; травник, знающий лес.
- «Глубокая магия» — редка, требует осознанного перестроения фундаментальных отношений, вызывает страх (связана с древними катастрофами).

---

## Цена (фундаментальный закон)

**Правило:** Любое изменение отношений изменяет самого изменяющего.

**MUST:**
- Если меняешь лес — лес меняет тебя.
- Цена — не наказание, а неизбежное следствие участия (Constraint Participation).
- actor_mutations вычисляются автоматически для каждого Proposal.
- Цена проявляется как изменение Relations актора: новые обязательства, ограничения, трансформация восприятия.

**ANTI-PATTERN:** «Потратить 20 маны на Fireball». Допустимо: «Кузнец куёт клинок → клинок меняет Relations владельца → владелец не может расстаться с клинком без Ritual of Severance».

---

## Ограничение

**Правило:** Нельзя устойчиво изменить отношения, которых не понимаешь.

**MUST:**
- Случайный эффект возможен, но нестабилен.
- Понимание → Подготовка → Действие → Последствие.
- Понимание само по себе ничего не делает.

---

## Духи и магия

**Правило:** Взаимодействие с духом — вхождение в систему взаимных обязательств.

**MUST:**
- Не приказ, не торговля — перестройка общей структуры отношений.
- Дух (Spirit Pattern) реагирует на Intent через резонанс.
- Переговоры с духами: предложение обязательств, перестройка общей структуры, не диалог в привычном смысле.

---

## Магия в обществе

**Правило:** Слабая магия повседневности vs глубокая магия.

**Слабая магия:**
- Кузнец, понимающий металл
- Травник, знающий лес
- Строитель, чувствующий камень
- Фермер, знающий землю

**Глубокая магия:**
- Редка
- Требует осознанного перестроения фундаментальных отношений
- Вызывает страх (связана с древними катастрофами)
- Изменяет тело, восприятие, память, социальные связи

**MUST:**
- Общество различает «допустимую» и «опасную» магию на практике, не через законы.
- Страх глубокой магии — один из источников конфликтов между культурами.

## Цепочка магического акта

```
Понимание → Подготовка → Действие → Последствие
```

**Понимание:**
- Игрок изучает Relations Pattern (лес, река, руины).
- Через Observation, исследование, переговоры с NPC.
- Понимание = способность предсказать, какие Relations изменятся.

**Подготовка:**
- Создание условий для изменения (ритуал, инструменты, союзники).
- Подготовка сама по себе может быть магическим актом.

**Действие:**
- Intent → Proposal → Validation → Commit.
- Магическое действие проходит через тот же Kernel, что и любое другое.
- Нет специального «магического канала».

**Последствие:**
- actor_mutations применяются автоматически.
- Изменение себя: тело, восприятие, память, социальные связи.
- Нет «прокачки» — есть трансформация.

## Примеры магических актов

### Пример 1: Ускорение роста леса
**НЕ:** Заклинание «ускорить рост» за 20 маны.
**ДА:**
1. Понимание Relations леса (влага, почва, дух-места)
2. Participation: ритуал, переговоры с духом, изменение русла ручья
3. Цена: игрок получает Relation `--bound to--> Forest_Vein`, ограничивающий свободу передвижения

### Пример 2: Ковка магического клинка
**НЕ:** «Клинок +3 к урону».
**ДА:**
1. Кузнец понимает Relations металла (геологическое происхождение, цикл нагрева, память ковки)
2. Ковка изменяет Relations клинка (привязка к владельцу, резонанс с духом кузни)
3. Цена: владелец не может расстаться с клинком без Ritual of Severance; клинок «помнит» каждую кровь

### Пример 3: Путешествие через нелокальность
**НЕ:** Fast-travel через меню.
**ДА:**
1. Понимание topological shortcuts в графе Relations региона
2. Подготовка: ритуал, следование древним дорогам, резонанс с местом
3. Действие: перемещение через «складку» пространства
4. Цена: игрок получает Relation `--marked by--> Ancient_Path`, влияющий на будущие путешествия

## Изменение игрока

**Правило:** Каждый магический акт или глубокое открытие изменяет способности, восприятие или ограничения персонажа.

**MUST:**
- Нет «прокачки» — есть трансформация.
- Изменение игрока = изменение его Relations с миром.
- Новые способности видеть связи, новые ограничения, новые восприятия.
- Игра сигнализирует об изменении через Observation, не через UI-уведомление.

**ANTI-PATTERN:** «Получен уровень 5, открыто заклинание Fireball». Допустимо: «После переговоров с духом реки игрок начинает видеть потоки влаги — новый тип Observation, но не может пересекать сухие зоны без Ritual».

## Анти-референсы (архитектурные запреты)

- Нет магии только как оружия
- Нет магических школ с каталогом заклинаний
- Нет маны как ресурса
- Нет «прокачки» магических навыков
- Нет избранного героя с особыми магическими способностями
